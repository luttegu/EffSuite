Core Computational Capabilities

Engineered to eliminate Excel/VBA limitations while preserving verified Fortran physics precision and strict metrological traceability.

⚡

Parallel Summing Calculations

Full cascade coincidence summing calculations executed across all CPU cores in one pass for every nuclide in the library, replacing serial workbook loops.

🧪

Dynamic NIST XCOM Engine

Integrated XCOM 3.1 photon cross-section calculation. Supports custom chemical matrices and instant sample bulk density scaling ($\rho / \rho_0$) on the fly.

📐

Live 2D CAD Cross-Sections

Dynamic axial cross-section view with collision-free dimension and quote callouts for cylindrical, Marinelli beaker, and well geometries.

🛡️

Non-Destructive File Export

Original vendor templates are never overwritten in place. Exported calibration and library files are verified through immediate round-trip readback.

💻

Headless Automation CLI

Automate LIMS workflows, batch-process CSV matrices, and replay GUI project files headlessly via EffSuite_CLI.exe or Python.

🔬

Audited Fortran Physics

Audited Fortran physics engines with density scaling, full-precision transfer factors, and tall-sample well boundary handling with double-precision token safety.

Dual Vendor Spectrometry Support

Seamlessly import reference curves and export summing-corrected libraries for the industry's two primary gamma spectrometry ecosystems.

Canberra / Mirion

Genie 2000 Integration

Automated CAM environment bridge with support for registered 32-bit and 64-bit vendor type libraries.

.CAL (Efficiency) .NLB (Nuclide Library) .CTF (Certificate)
  • Transfers efficiency to sample geometry: *_sample.CAL.
  • Divides gamma line abundance by summing factor $C$: *_corrected.NLB.
  • Updates certificate emission rates: *_corrected.CTF.
  • Automated COM verification on reopened copies before publication.
ORTEC (Untested — Call for Testers)

GammaVision Integration

Pure-Python non-destructive implementation matching Tim Vidmar's original gv.f and EFFTRAN.EFT format routines.

.EFT (Efficiency) .LIB (Nuclide Library) _gv.txt (Audit Table)
  • Reads & writes 128-byte binary direct-access records (EFFTRAN.Lib layout).
  • Parses both 11-token (EFFTRAN) and 5-token (MEFFTRAN) .EFT layouts.
  • Exports matching `_gv.txt` reports with energy, old/new yields, and factors.
  • Zero external dependencies — runs out-of-the-box on any Windows machine.

Command-Line & Scripting Integration

EffSuite is built for automation. Call it directly from Python, C#, PowerShell, or batch scripts.

EffSuite_CLI.exe cylinder \ --detector "High-energy" \ --standard "Solution" \ --sample "Water" \ --sample-height 55.0 \ --sample-density 1.000 \ --calibration "C:\Data\Standard.CAL" \ --library "C:\Data\NUTECH.NLB" \ --output-cal "C:\Output\Sample.CAL" \ --output-nlb "C:\Output\Corrected.NLB" \ --workers 4
