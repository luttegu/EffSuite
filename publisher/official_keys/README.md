# EffSuite Official Publisher Keys

This directory contains the official publisher public verification key and sample licence for EffSuite:

- **`effsuite_publisher_public.json`**: Official Ed25519 public verification key (`Key ID: 2b826ad66827d95e880b7735e90d1ecc`), embedded in `src/effsuite/licensing/config.py`.
- **`default_lab_license.efflic`**: Ready-to-use laboratory licence issued to *"Gamma Spectrometry Laboratory"* valid through 2030.

> **Security Note:** Private signing keys (`*.pem`) must be kept strictly confidential on offline publisher workstations and never committed to version control.
